Referencia oficial autorizada para Prueba 1 y Prueba 2

Tema 1: Aritmética y Álgebra

1.2 Progresión aritmética: $u_n = u_1 + (n-1)d$

$S_n = \frac{n}{2}(2u_1 + (n-1)d) = \frac{n}{2}(u_1 + u_n)$

1.3 Progresión geométrica: $u_n = u_1 r^{n-1}$, $S_n = \frac{u_1(r^n - 1)}{r - 1}$

1.4 Interés compuesto: $FV = PV \times \left(1 + \frac{r}{100k}\right)^{kn}$

1.9 Teorema del binomio: $(a+b)^n = a^n + \binom{n}{1}a^{n-1}b + \dots + \binom{n}{r}a^{n-r}b^r + \dots + b^n$

Tema 2: Funciones

2.1 Ecuación de la recta: $y = mx + c$; $ax + by + d = 0$; $y - y_1 = m(x - x_1)$

Pendiente: $m = \frac{y_2 - y_1}{x_2 - x_1}$; perpendiculares: $m_1 m_2 = -1$

2.6 Eje de simetría de $f(x)=ax^2+bx+c$: $x = -\frac{b}{2a}$

2.7 Fórmula cuadrática y discriminante: $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$, $\Delta = b^2 - 4ac$

Tema 3: Geometría y Trigonometría

3.2 Teorema del seno: $\frac{a}{\operatorname{sen} A} = \frac{b}{\operatorname{sen} B} = \frac{c}{\operatorname{sen} C}$

Teorema del coseno: $c^2 = a^2 + b^2 - 2ab\cos C$; $\cos C = \frac{a^2 + b^2 - c^2}{2ab}$

Área del triángulo: $A = \frac{1}{2}ab\operatorname{sen} C$

3.5 Identidad pitagórica: $\cos^2 \theta + \operatorname{sen}^2 \theta = 1$

3.6 Ángulo doble: $\operatorname{sen}(2\theta) = 2\operatorname{sen}\theta\cos\theta$; $\cos(2\theta) = \cos^2\theta - \operatorname{sen}^2\theta = 2\cos^2\theta - 1 = 1 - 2\operatorname{sen}^2\theta$

Tema 4: Estadística y Probabilidad

4.2 Media: $\bar{x} = \frac{\sum_{i=1}^k f_i x_i}{n}$, donde $n = \sum_{i=1}^k f_i$

4.3 Rango intercuartil: $\text{RIC} = Q_3 - Q_1$ (atípicos si $x < Q_1 - 1.5\,\text{RIC}$ o $x > Q_3 + 1.5\,\text{RIC}$)

4.5 Probabilidad de unión: $P(A \cup B) = P(A) + P(B) - P(A \cap B)$

Mutuamente excluyentes: $P(A \cap B) = 0$

4.6 Probabilidad condicionada: $P(A \mid B) = \frac{P(A \cap B)}{P(B)}$
